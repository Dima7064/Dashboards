# 📊 Анализ продаж интернет-магазина — дашборд в Power BI

> **Интерактивный дашборд для мониторинга выручки, региональных продаж, эффективности скидок и сезонности.**  

## 🔍 О проекте

**Цель:** создать многостраничный интерактивный дашборд, который позволяет бизнесу отслеживать ключевые метрики, выявлять точки роста и принимать решения на основе данных.

**Исходные данные:**  
- 240 транзакций интернет-магазина (январь 2023 – апрель 2024)  
- Поля: дата заказа, ID заказа, регион, категория, товар, количество, цена, скидка  
- Размер данных: 120 товарных позиций в 50 заказах от 50 уникальных клиентов

**Инструменты:**
- **Power BI Desktop** — построение дашборда и визуализация
- **DAX** — вычисляемые меры (выручка, средний чек, рост месяц к месяцу и др.)
- **Excel** — подготовка исходной таблицы
- **Power BI Service** — публикация и создание публичной ссылки

## 🖥️ Дашборд: страницы и ключевые возможности

### 1. Главная страница — KPI и динамика
- Карточки с общей выручкой, числом заказов, средним чеком и количеством клиентов
- Линейный график выручки по месяцам (с линией тренда)
- Круговая диаграмма выручки по категориям
- Срезы (фильтры): год, квартал, категория, регион

### 2. Товары и регионы
- Круговой график выручки по регионам
- Гистограмма выручки по товарам
- Общая выручка по категориям
- Матрица по товарам

## 📈 Ключевые инсайты (из PDF-отчёта)

1. **Доминирование электроники** — категория генерирует **64%** всей выручки, при этом ноутбуки имеют низкую скидку (3%) и самую высокую маржинальность.
2. **Ярко выраженная сезонность** — пик продаж в марте–апреле, летний спад (в 3–4 раза). Рекомендованы сезонные акции и расширение ассортимента «Спорт/Дом» на лето.
3. **Регионы-лидеры** — «Юг» (35% выручки) и «Запад» (26%). Регион «Восток» отстаёт (15%) — требуется адаптация маркетинговой стратегии.
4. **Неэффективные скидки** — на джинсы и кроссовки даётся скидка 7–8%, но они не входят в топ продаж. Рекомендовано снизить скидки до 4–5% для сохранения маржи.
5. **Товары-магниты** — мячи и футболки продаются большими объёмами (70+ штук), но имеют низкую цену. Их можно использовать для кросс-продаж с дорогими товарами.

## 🛠️ Использованные технологии и приёмы

- **Моделирование данных:** создана таблица календаря (`CalendarTable`) с полями год, месяц, квартал, неделя. Установлена связь с основной таблицей по дате.
- **Меры DAX (10+ мер):**  
  - `Total Revenue`, `Total Orders`, `Average Order Value`  
  - `Revenue MoM Growth %` (рост месяц к месяцу)  
  - `Unique Customers`, `Orders with Discount %`
- **Визуальные улучшения:** условное форматирование фона в таблице, кнопки навигации между страницами, динамические заголовки, подсказки (tooltips) с доп. графиками.
- **Параметр What-If:** слайдер для прогнозирования выручки при изменении целевого роста.
